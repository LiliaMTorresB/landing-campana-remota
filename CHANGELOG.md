## [1.0.0] - 2026-06-29

### Añadido
- Estructura base de la Landing Page Política (`index.html`).

- Estilos globales del sitio y diseño responsive (`css/estilos.css`).
- Interactividad básica en el botón de apoyo mediante alertas de JavaScript (`js/script.js`).
- Automatización mediante GitHub Actions para validar la estructura del proyecto (`.github/workflows/ci.yml`).
- Plantillas del repositorio: `PULL_REQUEST_TEMPLATE.md` y `feature_request.md`.
